# Product Hunt Launch Copy

## Product Name
HalalSEO AI

## Tagline
Generate SEO-ready halal restaurant pages in seconds

## Short Description
HalalSEO AI helps restaurant directories, food bloggers and local SEO teams generate polished halal restaurant pages from only a restaurant name and address.

## Long Description
HalalSEO AI is an AI-powered content generator built for halal restaurant directories and local food websites. Instead of manually writing hundreds of restaurant profiles, users can enter a restaurant name and address and instantly receive a search-friendly page with a meta description, location-aware content, halal status prompts, cuisine highlights, dining experience copy, nearby landmarks, parking notes and WordPress-ready HTML.

It is designed for directory owners, SEO teams and food bloggers who need consistent, useful and human-like content at scale.

## Founder First Comment

## Key Features
- Generate restaurant SEO pages from name + address
- 150-character meta description
- WordPress-ready HTML output
- Built for halal restaurant directories
- Location-aware copy with suburb, postcode and landmark context
- Halal status prompts for certification, alcohol and pork verification
- Useful for bulk local SEO content production
